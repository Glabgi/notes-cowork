# Design notes — копия фронтенда nalog.gov.ru (ФНС России)

Учебная вёрстка. Бэкенд не трогаем. Ниже — конспект дизайна оригинала.

## Источник данных и честная оговорка

Живой сайт `www.nalog.gov.ru` **недоступен** из рабочего окружения (egress-прокси
блокирует домен и web.archive.org). Поэтому замеры сделаны по **5 PDF-скриншотам**
страниц, которые прислал заказчик:

| Док | Страница | Ширина захвата |
|-----|----------|----------------|
| doc3 | **Главная** (16:41 12.08.2026) | 642 px — мобильная |
| doc1 | Контакты и обращения | 642 px — мобильная |
| doc2 | Нормативные правовые акты (О ФНС) | 642 px — мобильная |
| doc4 | О ФНС России | 642 px — мобильная |
| doc5 | Деятельность | 642 px — мобильная |

**Все пять захватов — мобильная версия (~375–414 CSS-px, бургер-меню).**
Значит:

- **Измерено точно** (вытащено из PDF программно): все hex-цвета, имена шрифтов,
  кегли, состав секций и порядок блоков мобильной раскладки.
- **Реконструировано / «угадано»**: вся десктопная и планшетная сетка (1440/1024/768),
  поведение горизонтального меню, ширина контейнера, hover/active/focus-состояния,
  тайминги анимаций. Оригинал в этих режимах я не видел — беру типовые значения
  дизайн-системы госсайтов ФНС и помечаю их как приближение. Полный список догадок —
  в разделе «Что угадано» и продублирован в Шаге 4.

## 1. Палитра (измерено из PDF)

```
--c-navy:        #3b4256;  /* тёмная верхняя панель «77 город Москва» */
--c-navy-text:   #272e42;  /* самый тёмный навигационный текст */
--c-ink:         #405965;  /* основной текст и заголовки (сине-серый) */
--c-link:        #0088ff;  /* ссылки */
--c-link-alt:    #3367cc;  /* доп. ссылочный синий */
--c-brand:       #0066b3;  /* фирменный синий (иконки, акценты разделов) */
--c-brand-deep:  #1b559e;  /* глубокий синий */
--c-orange:      #f15a22;  /* кнопка «Найти», активная точка слайдера */
--c-green:       #0bbb3c;  /* боковой ярлык «Ваш контроль» */
--c-gray-tab:    #808d9c;  /* боковой ярлык «Отзыв о сайте» */
--c-red:         #ed1c24;  /* акцент (флаг/эмблема) */

--bg-page:       #f4f7fc;  /* фон страницы, чуть голубой */
--bg-panel:      #e9ebf0;  /* панели, шапка аккордеона «Содержание страницы» */
--bg-card:       #ffffff;  /* карточки, поля */
--c-muted:       #a9a9a9;  /* плейсхолдер «Поиск» */
--c-border:      #e0e4ea;  /* границы карточек/разделителей (приближение) */
```

Контраст `#405965` на `#ffffff` ≈ 7.4:1, `#405965` на `#f4f7fc` ≈ 6.9:1 — проходит AA.
Оранжевый `#f15a22` с белым текстом ≈ 3.4:1 — для крупного текста кнопки (≥18px bold)
проходит AA, что и есть у «Найти».

## 2. Типографика (измерено)

| Роль | Шрифт (оригинал) | Кегль | Цвет |
|------|------------------|-------|------|
| Крупные заголовки («Физические лица», H1 страниц) | **PF DIN Text Cond Pro Medium** (узкий) | 28.8 pt | `#405965` |
| Заголовки блоков («Новости», «Содержание страницы») | тот же узкий, bold | ~20.8 pt | `#405965` |
| Тело / пункты меню | Helvetica → в реале PT Astra Sans / Arial | 16 pt | `#405965` |
| Вторичный текст, ссылки списков | тот же | 15 / 14 pt | `#405965` / `#0088ff` |
| Мелкие подписи («ОФИЦИАЛЬНЫЙ САЙТ», текст ярлыков) | тот же, uppercase | 11.2 pt | `#405965` / `#fff` |

- Основной шрифт заголовков — **проприетарный PF DIN Text Cond Pro**, шить его нельзя.
  В копии беру бесплатный узкий гротеск-заменитель (self-hosted через `@fontsource`,
  напр. **PT Sans Narrow** / **Oswald**) + системный фолбэк. Это приближение по начертанию.
- Тело — системный стек `-apple-system, "Segoe UI", "PT Astra Sans", Arial, sans-serif`.
- Интерлиньяж измерить по PDF точно нельзя; беру ~1.3 для тела, ~1.1 для крупных
  заголовков (приближение).
- Заголовки набраны почти без «воздуха», плотно, medium-насыщенность.

## 3. Сетка, контейнер, отступы

**Измерено (мобилка, 642px-захват):**
- Контент — колонка карточек на фоне `#f4f7fc`; карточки белые во всю ширину с
  боковыми полями ~20–22px.
- Вертикальный ритм между карточками ~14–16px.
- Внутренние отступы карточек ~20px.
- Шапка: эмблема слева, бургер справа; строка поиска — отдельная белая полоса.

**Реконструировано (десктоп, приближение):**
- Контейнер `max-width: 1180px`, центрирован, боковые поля 16px.
- Верхняя строка «регион» — во всю ширину, высота ~44px.
- Основная шапка: эмблема + название слева, горизонтальное меню/иконки справа.
- Главная на десктопе: три промо-блока (ФЛ/ИП/ЮЛ) в ряд или крупной сеткой,
  под ними — поиск, сетка карточек-сервисов 2–3 колонки, блок «Новости» со слайдером,
  блок «Обратиться в ФНС».
- Боковые «липкие» ярлыки «Отзыв о сайте» и «Ваш контроль» — фиксированы у правого
  края (`position: fixed`), вертикальный текст.

## 4. Радиусы, тени, границы

- Радиусы: поля/кнопки/карточки — небольшие, ~2–4px (близко к прямоугольным). *(приближение)*
- Тени: у карточек почти нет; лёгкая `0 1px 2px rgba(0,0,0,.06)` для отрыва от фона. *(приближение)*
- Разделители: тонкие линии `#e0e4ea`; под H1 страницы — **яркая синяя линия**
  (`#0088ff`/`#0066b3`, толщина ~3px) — это измерено (видно на «Деятельность»,
  «Нормативные акты»).

## 5. Состояния кнопок и ссылок

**Измерено:** «Найти» — сплошной оранжевый `#f15a22`, белый bold-текст, прямоугольная.
Ссылки — синие `#0088ff`, без подчёркивания в спокойном состоянии.

**Приближение (не видно на статичных PDF):**
- Ссылка hover: подчёркивание + затемнение до `#0066b3`.
- Кнопка hover: `#d94f1d` (оранжевый темнее ~8%); active: ещё темнее + лёгкий сдвиг.
- Focus (для доступности): видимая обводка `2px` `#0088ff` с отступом (`outline-offset`).
- Пункты меню/аккордеона hover: фон `#e9ebf0`.

## 6. Компоненты (по скриншотам)

1. **Верхняя панель региона** — тёмная `#3b4256`, по центру пин + «77 город Москва» +
   шеврон вниз (открывает выбор региона).
2. **Шапка** — эмблема ФНС (герб в круге), в две строки «ФЕДЕРАЛЬНАЯ НАЛОГОВАЯ СЛУЖБА»
   и мелким «ОФИЦИАЛЬНЫЙ САЙТ»; справа бургер (мобилка).
3. **Поиск** — белое поле «Поиск» + оранжевая кнопка «Найти».
4. **Промо-блоки ФЛ/ИП/ЮЛ** — фото человека слева, крупный заголовок, ссылки
   «Личный кабинет», «Скачать моб. приложение».
5. **Карточки-сервисы** — иконка слева + текст, белые карточки в столбик
   («Налоги 2026», «Новый порядок погашения задолженности», «Как получить ЭП»,
   «Обратиться в ФНС России» и т.д.).
6. **Блок «Новости»** — заголовок со стрелкой + **слайдер**: фото, точки-пагинация
   (активная оранжевая), стрелки ‹ ›, подпись поверх затемнения.
7. **Блок «Обратиться в ФНС»** — синяя плашка, три иконки-канала
   (чат-бот / по телефону / обращение), список ссылок с иконками.
8. **Слайдер баннеров** — тёмно-синие баннеры со стрелками.
9. **Хлебные крошки** (внутренние страницы) — «Главная страница › Раздел».
10. **H1 страницы + иконка печати** + синяя подчёркивающая линия.
11. **Аккордеон «Содержание страницы»** — серая шапка `#e9ebf0`, пункты с шевроном-вниз
    в кружке, раскрываются.
12. **Счётчик** — «всего: 1551» под заголовком (на страницах-списках).
13. **Сетка иконочных ссылок** (страница «Деятельность») — крупная иконка по центру,
    синяя подпись под ней, короткое подчёркивание.
14. **Футер** — светло-серый `#e9ebf0`: колонки ссылок с иконками (Программные средства,
    Вакансии, Контакты, Открытые данные, Карта сайта, RSS…), логотипы партнёров
    (Правительство России, Госуслуги, Открытое правительство), соц-иконки
    (VK, OK, Telegram, …), «© 2005–2026 ФНС России», «Дата обновления страницы …».

## 7. Брейкпоинты (план адаптива)

Требуется поддержка **1440 / 1024 / 768 / 375**.

- **≥1200 (1440):** контейнер 1180px, горизонтальное меню, промо ФЛ/ИП/ЮЛ в ряд,
  карточки-сервисы 3 колонки, боковые липкие ярлыки видны. *(реконструкция)*
- **1024:** тот же контейнер уже экрана, сервисы 2–3 колонки, меню сжимается. *(реконструкция)*
- **768 (планшет):** появляется бургер, промо-блоки 1–2 колонки, сервисы 2 колонки. *(реконструкция)*
- **375 (мобилка):** ровно как на скриншотах — всё в одну колонку, бургер,
  поиск отдельной полосой, слайдеры со стрелками. *(измерено)*

## 8. Анимации и переходы

Ничего динамического на PDF не видно, поэтому — типовые значения *(приближение)*:
- Ссылки/кнопки/hover: `transition: .15s ease`.
- Аккордеон: плавное раскрытие высоты `.2s ease`.
- Бургер-меню: выезд/фейд панели `.25s ease`.
- Слайдеры: смена слайда `.4s ease`, авто-прокрутка новостей ~5s (заглушка).

## 9. Что угадано (сводка для Шага 4)

1. Весь **десктоп/планшет** (1440/1024/768): сетка, ширина контейнера 1180px,
   горизонтальное меню, раскладка промо и карточек.
2. **Радиусы** (~2–4px) и **тени** карточек.
3. **Интерлиньяж** (1.3 / 1.1).
4. Все **hover/active/focus** цвета (ссылок, кнопок, пунктов меню).
5. **Тайминги** анимаций и автопрокрутки слайдеров.
6. Точная **толщина/оттенок** некоторых границ (`#e0e4ea`).
7. Замена проприетарного **PF DIN Text Cond Pro** на бесплатный узкий гротеск.
8. Точные **пиксельные отступы** десктопа (на мобилке измерены приблизительно по растру).
