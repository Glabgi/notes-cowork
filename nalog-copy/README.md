# Учебная копия фронтенда nalog.gov.ru (ФНС России)

Только вёрстка: чистый HTML + CSS + ванильный JS. Без бэкенда, БД, API,
авторизации, localStorage и внешних сетевых запросов.

## Запуск локально

Сервер не нужен — это статические файлы.

**Вариант 1 (проще всего):** открыть `index.html` двойным кликом в браузере.

**Вариант 2 (рекомендуется, чтобы гарантированно подхватились шрифты):**
из папки `nalog-copy/` запустить локальный сервер и открыть в браузере:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Проверка адаптива: DevTools (F12) → режим устройства, ширины 1440 / 1024 / 768 / 375.

## Структура

```
nalog-copy/
├─ index.html          главная
├─ about.html          внутренняя страница-образец (крошки, аккордеон, плитки)
├─ design-notes.md     конспект дизайна оригинала (замеры + пометки «угадано»)
├─ css/
│  ├─ fonts.css        @font-face (Oswald, self-hosted)
│  ├─ variables.css    :root — токены (цвета/шрифты/отступы)
│  ├─ base.css         reset + типографика + доступность
│  ├─ layout.css       контейнер, сетки, брейкпоинты
│  └─ components.css   все компоненты
├─ js/main.js          бургер, регион, аккордеон, слайдеры, валидация
└─ assets/
   ├─ fonts/           woff2 (Oswald)
   └─ img/             emblem.svg (плейсхолдер эмблемы)
```

## Что интерактивно (на фронте, без сервера)

- Мобильный бургер-меню с оверлеем (Esc закрывает).
- Выпадающий выбор региона (меняет подпись в верхней панели).
- Аккордеон «Содержание страницы».
- Два слайдера (новости — с автопрокруткой; баннеры) — стрелки + точки.
- Поиск: клиентская валидация пустого поля + заглушка результата (тост).
  Форма никуда не отправляется.

## Оговорки

- Оригинал `nalog.gov.ru` был недоступен из рабочего окружения, поэтому
  замеры сделаны по мобильным PDF-скриншотам. Мобильная раскладка —
  измерена; десктоп/планшет — реконструкция. Подробности и список
  «угаданных» значений — в `design-notes.md`.
- Эмблема ФНС и фотографии заменены плейсхолдерами (оригиналы скачать было нельзя).
- Проприетарный шрифт PF DIN Text Cond Pro заменён свободным Oswald.
